# 🛍️ Nykaa Product Analysis — Web Scraping & Data Analytics

## 📌 Overview

An end-to-end data analytics project that collects and analyzes Nykaa product data from three categories:

- 🏥 Healthcare
- 💄 Beauty
- 👶 Baby

The project covers **web scraping, data cleaning, EDA, visualization, and Power BI dashboard development**.

## 🎯 Objectives

- Collect product data using Python and Selenium
- Clean and preprocess the data using Pandas
- Perform Exploratory Data Analysis (EDA)
- Analyze prices, discounts, ratings, and reviews
- Create an interactive Power BI dashboard
- Generate business insights and recommendations

## 🛠️ Tools & Technologies

- Python
- Selenium
- BeautifulSoup
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Excel
- Power BI
- Jupyter Notebook

## 📊 Dataset

**Total Products:** 82

| Category | Products |
|---|---:|
| Healthcare | 31 |
| Beauty | 31 |
| Baby | 20 |
| **Total** | **82** |

## 🔍 Key Findings

- Healthcare has the highest average selling price: **₹1,460.74**
- Healthcare has the highest average discount: **17.90%**
- Beauty has the highest average rating: **4.37/5**
- Beauty has the highest total written reviews: **179,021**
- Baby has the lowest average selling price: **₹630.75**

## 📈 Power BI Dashboard

The dashboard includes:

- Total Products
- Average Selling Price
- Average Discount
- Average Rating
- Products by Category
- Price Range Distribution
- Top 10 Products by Reviews
- Selling Price vs Review Count
